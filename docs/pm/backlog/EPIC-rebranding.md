# Epic: Visual identity redesign and rebranding

- **Status**: planned
- **Release**: TBD (post-Priority 2)
- **Goal**: Transform from sterile "Travel Intelligence Hub" to a memorable, visually engaging brand with personality and thematic depth
- **Why now**: Current name and appearance don't reflect the product's power or delight users. Rebranding increases memorability, engagement, and positions app as premium travel planning tool.

## Scope

**Phase 1: Naming & Brand Strategy**
- Brainstorm 20+ name candidates
- Evaluate for: memorability, domain availability, cultural sensitivity, visual potential
- Select winning name with rationale
- Develop brand voice and personality statement

**Phase 2: Visual Design System**
- Color palette redesign (move from minimal gray to vibrant, travel-themed palette)
- Typography and iconography refresh
- Illustration style for empty states and onboarding
- Photography direction (curated travel imagery)
- Visual patterns and textures (travel-inspired)

**Phase 3: Implementation**
- Update logo and favicon
- Rollout new colors across all pages
- Add hero imagery to key pages (landing, signup, trips overview)
- Watermark/pattern overlays for depth
- Implement new illustration system
- Update documentation and brand guidelines

**Phase 4: Polish & Refinement**
- User feedback and iteration
- Edge case styling (dark mode alignment)
- Performance optimization for imagery
- Brand guidelines documentation

## Name Brainstorming

### Candidates to explore:
- **Wanderwise** - combines wanderlust + wisdom, playful but intelligent
- **Compass** - simple, iconic, direction/navigation theme (may be too generic)
- **Voyager** - adventurous, timeless, premium feel
- **Pathfinder** - explores options like comparing, journey-oriented
- **Sojourn** - literary, sophisticated, means "brief visit"
- **Traverse** - travel-specific, active, technical feel
- **Altitude** - elevation of travel planning, aspirational
- **Bearings** - navigation term, grounded, directional
- **Jetway** - modern, travel-focused, energetic
- **Drift** - exploring possibilities, casual luxury
- **Nomad** - travel lifestyle, community-oriented
- **Horizons** - aspirational, implies discovery
- **Waypoint** - navigation term, practical yet poetic
- **Embark** - departure, adventure, action-oriented
- **Passage** - journey-oriented, sophisticated
- **Expedite** - action-packed, forward motion
- **Locale** - focus on destinations, modern
- **Seekers** - explorers, community feel
- **Terrain** - geo-focused, earthy, natural
- **Confluence** - meetings of interests/travel options

### Final selection criteria:
- Memorable and pronounceable
- Available as domain (.com, .app, .travel)
- Suggests travel/exploration/planning
- Visual potential (logo, icon, imagery)
- Positive cultural connotations
- Scalable (can be "Wanderwise Pro," "Wanderwise Teams," etc.)

## Visual Direction

### Color Palette
**Primary: Warm & Adventurous**
- Sunset Orange: #FF6B35 (energy, exploration)
- Deep Teal: #004E89 (trust, depth like ocean)
- Cream: #FFF8E7 (warmth, accessibility)

**Secondary: Supporting Tones**
- Sand: #E8D5C4 (desert, natural)
- Forest Green: #2D6A4F (nature, sustainability)
- Sky Blue: #87CEEB (adventure, freedom)
- Charcoal: #2B3E50 (sophistication)

### Imagery & Patterns
- **Hero imagery**: Curated travel photography (destinations, moments, local culture)
- **Illustrations**: Hand-drawn travel icons (plane, map, compass, wanderer)
- **Watermarks**: Subtle passport stamps, map grids, travel ephemera
- **Textures**: Vintage map overlay, linen background, travel diary aesthetic

### Typography
- **Headings**: Playfair Display (elegant, editorial)
- **Body**: Inter (modern, readable, accessible)
- **Accent**: Courier Prime (travel journal, retro feel)

## Acceptance Criteria
