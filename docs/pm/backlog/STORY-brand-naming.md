# Story: Brand naming and strategy

- **Epic**: Visual identity redesign
- **Status**: planned
- **Size**: M
- **Scope**: design | strategy

## User story
As a founder, I want to rebrand from "Travel Intelligence Hub" to something memorable and distinctive that reflects the product's power and appeal to travelers.

## Acceptance criteria

**Name Selection Process:**
- [ ] Research phase: 20+ name brainstorm candidates evaluated
- [ ] Domain availability checked for top 5 candidates
- [ ] Trademark/legal check completed (no conflicts)
- [ ] Cultural sensitivity review (no negative connotations)
- [ ] Pronunciation test with 10+ people (memorability)
- [ ] Visual/logo potential evaluated (does it lend itself to design?)
- [ ] Winning name documented with rationale

**Brand Strategy Document:**
- [ ] Brand purpose: "Why does this app exist?"
- [ ] Target audience definition
- [ ] Brand personality (tone, voice, values)
- [ ] Unique value proposition vs competitors
- [ ] Tagline or brand promise
- [ ] Visual direction brief
- [ ] Example usage in marketing (taglines, headlines)

**Domain & Assets:**
- [ ] Primary domain registered (.com preferred, .app as backup)
- [ ] Email alias set up (hello@[newdomain])
- [ ] Social handles reserved on: Twitter, Instagram, LinkedIn
- [ ] GitHub org updated (if public)
- [ ] Email signature template created

**Documentation:**
- [ ] Brand naming rationale memo (1-2 pages)
- [ ] Competitor naming analysis (why chosen name stands out)
- [ ] Pronunciation guide with IPA
- [ ] Etymology/meaning explanation
- [ ] Approved naming guidelines (capitalization, usage)

## Name Recommendation

Based on the criteria, **Wanderwise** is recommended:

✅ **Memorability**: Compound word, easy to say, 9 letters  
✅ **Meaning**: Combines "wander" (exploration) + "wise" (intelligent planning)  
✅ **Visual**: Logo potential - compass/path mark, illustrative  
✅ **Domain**: wanderwise.com, wanderwise.app available  
✅ **Personality**: Friendly + sophisticated, appeals to explorers + planners  
✅ **Scalability**: "Wanderwise Pro", "Wanderwise Teams", "Wanderwise for Travel Agents"  
✅ **Cultural**: Positive globally, no negative connotations  

Alternative choices if Wanderwise unavailable:
1. **Horizons** - aspirational, discovery-focused
2. **Voyager** - premium, timeless, adventure-oriented
3. **Pathfinder** - exploration, comparative features
