# Epics

Large bodies of work spanning multiple stories/sessions. Keep epics
high-level — break detail into stories in this same folder
(`STORY-<epic-slug>-<n>.md`).

---

## Template (copy for each new epic)

### Epic: <name>
- **Status**: planned | in progress | done
- **Goal**: <the strategic objective, one or two sentences>
- **Why now**: <why this matters, priority rationale>
- **Stories**: <list of story files under this epic>
- **Dependencies**: <other epics/stories this needs first, if any>
